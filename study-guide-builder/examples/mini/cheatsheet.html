Core idea

Store key k at index h(k) of an array of size m. Average lookup, insert and delete are O(1).

Hash function (division method)

h(k) = k mod m. Needs to be deterministic, fast, uniform.

Collision

Two keys, one index. Unavoidable when keys outnumber slots.

Load factor

α = n / m. Resize (double + rehash) when α passes the threshold.

Costs

  • Expected search, chaining: ≈ 1 + α/2
  • Worst case (all keys collide): O(n)
  • Resize: O(n), amortised O(1) per insert

Remember

  • Same key, same slot.
  • Rehash on resize, because m changed.
  • Delete in probing tables needs tombstones.
